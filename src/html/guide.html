Panduan Penggunaan

Untuk Dosen / Moderator

  1. Login dengan email kampus, lalu buka Dasbor → Meeting Saya.
  2. Pilih Mulai Meeting Sekarang, Buat untuk Nanti, atau Jadwalkan Meeting. Setiap room memiliki ID, password, link moderator, dan link peserta.
  3. Bagikan link peserta (atau ID + password) ke mahasiswa. Jangan bagikan link moderator.
  4. Di dalam room: unggah materi PDF lewat tombol + → Kelola presentasi, gunakan alat whiteboard di sisi kanan slide (klik tombol panah di atas alat untuk menyembunyikannya agar slide tidak tertutup), mulai polling, atau bagikan layar.
  5. Klik ikon roda gigi di daftar Pengguna untuk Mute semua, Kunci peserta (lock viewers), atau Simpan daftar nama. Klik nama peserta untuk menjadikan presenter, moderator, mute, atau mengeluarkan.
  6. Rekam menyimpan rekaman ke komputer Anda (tidak membebani server). Semua peserta melihat indikator saat rekaman berjalan.
  7. Sorot kamera: arahkan kursor ke kamera peserta lalu klik Sorot (atau klik nama peserta → Sorot kamera). Kamera tersebut tampil besar untuk semua orang dan bisa ditonton layar penuh. Klik Hentikan sorotan untuk kembali.
  8. Event: buat di Dasbor → Event. Password 6 karakter bersifat opsional (tombol Acak). Isi nama & jabatan penanda tangan sertifikat dan, bila perlu, logo sponsor. Bagikan link event; peserta yang login langsung bisa bergabung tanpa mendaftar. Daftar hadir bisa diunduh dalam PDF/Excel.

Untuk Mahasiswa / Peserta

  1. Buka link dari dosen, atau masukkan ID room di beranda lalu isi password.
  2. Isi Nama Tampilan sesuai nama & NIM agar mudah diabsen.
  3. Pilih Mikrofon untuk ikut bicara atau Hanya mendengar bila sinyal lemah (paling hemat kuota).
  4. Gunakan Angkat tangan untuk bertanya, dan chat untuk mengirim pertanyaan tertulis.
  5. Event: login, buka link event, klik Gabung ke Event, lalu masukkan password bila diminta (cukup sekali). Room dibuka 30 menit sebelum acara.
  6. Menu kiri (chat, catatan, transkrip, pengguna) terlipat saat masuk agar layar utama tampil besar. Klik ikon ☰ di kiri atas untuk membukanya; titik merah menandakan ada pesan baru.
  7. Latar virtual sendiri: klik ikon kamera → Latar virtual → Unggah. Gambar (PNG/JPG/WebP) hanya disimpan di perangkat Anda, maksimal 4 gambar.
  8. Transkrip & terjemahan: di panel Transkrip, pilih Bahasa ucapan saya dan Terjemahkan ke (English/Indonesia). Terjemahan tampil di transkrip dan teks langsung (CC) sesuai pilihan masing-masing peserta. Terjemahan di perangkat paling baik di Chrome/Edge versi terbaru di laptop/PC. Rekaman menampilkan teks asli beserta terjemahannya. Transkrip dapat diunduh dalam PDF, Word, atau teks lewat tombol unduh di panel Transkrip maupun di Dasbor.

Keamanan & Privasi

  • Audio/video terenkripsi di jalur jaringan (DTLS-SRTP, wajib pada WebRTC) dan semua halaman melalui HTTPS.
  • Password akun disimpan dengan hash scrypt; sesi menggunakan cookie HttpOnly + proteksi CSRF.
  • Room dilindungi password atau link undangan acak; percobaan menebak password dibatasi (rate limit).
  • Moderator dapat mengunci fitur peserta, mengeluarkan dan memblokir peserta, serta mengakhiri meeting untuk semua.
  • Data tersimpan di server kampus sendiri; rekaman disimpan di perangkat perekam, bukan di server.

FAQ

Kamera/mikrofon tidak terdeteksi?

Klik ikon gembok di address bar browser, izinkan Kamera & Mikrofon, lalu muat ulang halaman. Pastikan tidak ada aplikasi lain yang sedang memakai kamera.

Suara putus-putus atau video patah-patah?

Buka menu ⋮ → Pengaturan dan aktifkan Mode hemat data, atau matikan kamera. Kualitas video otomatis menyesuaikan jaringan.

Dokumen Word/PowerPoint tidak bisa diunggah?

Simpan/ekspor terlebih dahulu ke PDF (File → Save as → PDF). PDF memberi hasil terbaik dan paling ringan.

Bagaimana memastikan sertifikat asli?

Pindai QR code di sertifikat dengan kamera HP. Halaman verifikasi menampilkan nama peserta, nama event, penanda tangan, waktu pelaksanaan, dan durasi kehadiran.

Kenapa sertifikat saya belum terbit?

Sertifikat terbit saat Anda keluar dari room dan total kehadiran sudah memenuhi durasi minimum yang ditetapkan panitia. Pastikan Anda login saat mengikuti event.
